# Smart ЖК AI Assistant

Учебный Telegram-бот для жителей вымышленного жилого комплекса Smart Residence в Казахстане. Бот показывает каталог, помогает подготовить черновик заявки и при настроенном Gemini отвечает на текстовые вопросы в личном чате и по обращению в группе.

## Запуск в Windows и VS Code

1. Откройте папку `smart-jk-assistant` через **File → Open Folder** в VS Code. В терминале PowerShell проверьте, что `python --version` показывает Python 3.13.7.
2. При первом запуске создайте виртуальное окружение и скопируйте пример настроек. Если `.env` уже существует, редактируйте этот файл.

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   Copy-Item .env.example .env
   ```

3. Получите токен через [@BotFather](https://t.me/BotFather) командой `/newbot`. Откройте `.env` в редакторе и впишите токен в строку `TELEGRAM_BOT_TOKEN=`. Храните токен локально.
4. Для ответов ассистента создайте ключ в [Google AI Studio](https://aistudio.google.com/apikey) и добавьте в существующий `.env` строку `GEMINI_API_KEY=` со своим ключом. Модель по умолчанию — `gemini-3.5-flash-lite`. При необходимости укажите другое имя модели через `GEMINI_MODEL`. С пустым ключом доступны меню, каталог и черновик заявки. [Документация Google по ключам](https://aistudio.google.com/docs/api-key)
5. В палитре команд VS Code выберите **Python: Select Interpreter** и укажите `.venv\Scripts\python.exe`. В новом терминале с активным окружением запустите бота. Если он уже работает, остановите текущий процесс через **Ctrl+C** и запустите его снова.

   ```powershell
   python -m bot.main
   ```

   Если активация окружения не выполняется, используйте `.\.venv\Scripts\python.exe -m bot.main`. Остановка через **Ctrl+C**. Для одного токена запускайте один процесс. [Документация aiogram по polling](https://docs.aiogram.dev/en/v3.27.0/dispatcher/long_polling.html)

## Ручная проверка в Telegram

1. В личном чате отправьте `/start`. Проверьте приветствие и кнопки меню.
2. Отправьте `/help` и `/services`. Проверьте список команд и демонстрационные услуги.
3. С настроенным Gemini отправьте «Есть ли сантехник?». Проверьте, что бот отвечает по демонстрационному каталогу. Затем спросите «Когда включат свет в подъезде?». Бот должен сообщить, что подтверждённого срока нет. Без ключа обычный текст вызывает подсказку с командами.
4. Вызовите `/request` и введите «В подъезде 2 не работает свет». Нажмите **Подтвердить**. Бот должен закрыть черновик и сообщить, что в учебном режиме заявка не отправлена. Повторите с кнопкой **Отменить** и командой `/cancel`. Используйте вымышленные данные. Состояние черновика хранится в памяти процесса, предварительный просмотр отображается в личном чате Telegram.
5. Добавьте бота в тестовую группу и проверьте `/help@имя_бота` и `/request@имя_бота`. Вторая команда должна предложить открыть личный чат. Затем проверьте текстовые ответы по сценариям ниже.

### День 3. Группа и языки

Замените `smart_jk_ai_bot` на username своего бота, если он отличается.

| Сообщение в группе | Ожидаемый результат |
| --- | --- |
| `Всем привет` | Бот молчит. |
| `/ask@smart_jk_ai_bot Есть ли электрик?` | Ответ по-русски на основе каталога. |
| `/ask@smart_jk_ai_bot Сантехник қызметі бар ма?` | Ответ по-казахски на основе каталога. |
| `/ask@smart_jk_ai_bot Сәлеметсіз бе, біздің подъезде свет жоқ, когда включат?` | Бот понимает вопрос о сроке и сообщает, что подтверждённой информации нет. |
| Ответ на сообщение бота с полным вопросом `Сколько стоит вызов сантехника?` | Бот отвечает, что стоимость уточняется. |
| `@smart_jk_ai_bot Есть ли клининг?` | Бот отвечает, если Telegram доставляет обычные упоминания. |

Оставьте Privacy Mode включённым для проверки адресных команд и ответов. Обычные упоминания Telegram может не доставлять. Для проверки упоминаний в отдельной тестовой группе можно отключить режим командой `/setprivacy` в @BotFather и заново добавить бота. [Режим приватности ботов Telegram](https://core.telegram.org/bots/features#privacy-mode)

Gemini получает текст текущего вопроса и демонстрационный каталог. Для групповых обращений бот убирает префикс команды или своё упоминание. История группы, исходное сообщение при ответе, сведения Telegram-профиля и содержимое черновиков остаются вне запроса. Используйте вымышленные данные и формулируйте каждый вопрос целиком в одном сообщении.

### День 4. Голосовые вопросы

Запишите голосовое микрофоном Telegram в личном чате. В тестовой группе запишите его как ответ на сообщение бота. Лимиты проекта — 60 секунд по данным Telegram и 2 МиБ на загрузку. Бот принимает голосовые OGG и отправляет аудио в Gemini для расшифровки. Используется тот же `GEMINI_API_KEY`.

Нажмите **Верно**, чтобы получить ответ. Если текст распознан с ошибкой, выберите **Исправить** и отправьте вопрос текстом. В группе используйте `/ask@smart_jk_ai_bot`. Подтвердить, исправить или отменить расшифровку может автор сообщения. Аудио обрабатывается в памяти. Бот хранит черновик расшифровки в памяти до подтверждения, исправления или отмены. Расшифровка отображается в том же чате, где записан вопрос.

[15 фраз и дополнительные сценарии для ручной проверки](docs/voice-tests.md)

### День 5. PostgreSQL и документы

1. Установите PostgreSQL и pgAdmin, если их ещё нет. При установке запомните пароль роли `postgres`. Для проекта создайте отдельную роль `smart_jk` с правом входа и базу `smart_jk` с владельцем `smart_jk`. В pgAdmin это можно сделать в дереве сервера через **Login/Group Roles → Create** и **Databases → Create**. [Установщик PostgreSQL для Windows](https://www.postgresql.org/download/windows/)
2. Добавьте строку в существующий `.env`. Подставьте пароль роли `smart_jk`, при необходимости замените адрес и порт. Спецсимволы в пароле URL, например `@` и `#`, кодируются как `%40` и `%23`. [Формат строки подключения PostgreSQL](https://www.postgresql.org/docs/current/libpq-connect.html#LIBPQ-CONNSTRING)

   ```dotenv
   DATABASE_URL=postgresql+psycopg://smart_jk:ВАШ_ПАРОЛЬ@127.0.0.1:5432/smart_jk
   ```

3. Из папки проекта обновите зависимости и примените миграцию.

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m alembic upgrade head
   ```

   Если ошибка миграции указывает на одиночный файл `mako.py` в папке установки Python, в этом же PowerShell укажите каталог пакетов виртуального окружения и повторите миграцию.

   ```powershell
   $env:PYTHONPATH = (Resolve-Path .\.venv\Lib\site-packages).Path
   .\.venv\Scripts\python.exe -m alembic upgrade head
   ```

4. Создайте учебный файл `rules.docx` с вымышленным правилом ЖК или сохраните его в PDF с выделяемым текстом. Положите файл рядом с README и выполните импорт.

   ```powershell
   .\.venv\Scripts\python.exe -m bot.documents import .\rules.docx --title "Правила Smart Residence" --public
   .\.venv\Scripts\python.exe -m bot.documents list
   ```

   Опции `--source-url` и `--revision-date ГГГГ-ММ-ДД` сохраняют ссылку и дату редакции, указанные при импорте. Для законов сверяйте эти сведения по официальному источнику перед публикацией. При повторном импорте того же файла сохраняется прежний ID. Флаг `--public` делает ранее импортированный документ доступным в каталоге.
5. Перезапустите бота и отправьте `/documents`. Бот показывает последние 10 публичных документов, со ссылкой на источник, если она указана. Без `DATABASE_URL` каталог недоступен, остальные команды работают.

Импорт сохраняет извлечённый текст и метаданные. Исходный файл остаётся у пользователя. Лимиты — 10 МиБ на файл, 200 страниц для PDF и 200 000 символов извлечённого текста. Для PDF-сканов сначала выполните OCR. DOCX читается с абзацами и таблицами, PDF — с номерами страниц.

### День 6. Поиск по документам

Примените миграцию и запустите индексацию после загрузки публичных документов. Используется существующий `GEMINI_API_KEY`.

```powershell
$env:PYTHONPATH = (Resolve-Path .\.venv\Lib\site-packages).Path
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m bot.knowledge_index
```

Индекс сохраняет фрагменты, статьи или страницы и 768-мерные векторы в PostgreSQL. Используется `gemini-embedding-001` и поиск по косинусной близости с учётом слов запроса. При временной ошибке Gemini поиск опирается на слова и номера статей. После импорта новых публичных документов повторите команду индексации. Если она прервалась, следующий запуск продолжит со фрагментов без векторов. [Документация Gemini по embeddings](https://aistudio.google.com/docs/embeddings)

Перезапустите бота и проверьте в личном чате:

- `/law Тұрғын үй қатынастары туралы заң бойынша кондоминиумның ортақ мүлкіне не жатады?`
- `/law Что относится к общему имуществу кондоминиума по закону о жилищных отношениях?`
- `/law Тұрғын үй қатынастары туралы заңның 9999-бабында не жазылған?`

В первых двух ответах проверьте содержание и ссылку на «Әділет». На вопрос о несуществующей статье бот должен ответить, что подтверждённых сведений нет. В группе используйте `/law@smart_jk_ai_bot`. Явно правовые вопросы направляются в поиск и при отправке обычным текстом.

Бот отправляет Gemini вопрос и найденные выдержки из публичных документов. Приложение проверяет цитаты по сохранённому тексту и формирует ссылки из метаданных PostgreSQL. Ссылки ведут к источникам, указанным при импорте. Для новых редакций загрузите актуальный текст, а публичность устаревшей записи снимите в базе перед индексацией.

### День 7. ЖК, заявки и каталог услуг

Примените миграцию и перезапустите бота.

```powershell
$env:PYTHONPATH = (Resolve-Path .\.venv\Lib\site-packages).Path
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m bot.main
```

Миграция добавляет учебный ЖК Smart Residence с корпусами `А` и `Б` и демонстрационными услугами. До привязки группы или выбора другого ЖК используется этот профиль.

1. В личном чате отправьте `/residence` и `/services`. Сравните карточку и каталог с данными ЖК. Можно спросить обычным текстом «ЖК-да неше пәтер бар?».
2. Отправьте `/request`. Введите корпус `А`, выберите **Освещение**, введите подъезд `2` и вымышленное описание. Проверьте черновик и нажмите **Подтвердить**. Бот выдаст номер только после записи в PostgreSQL.
3. Отправьте `/status` или `/status 12` со своим номером. В группе `/status` ведёт в личный чат. Повторный запрос с того же подтверждения не создаёт вторую запись.

#### Настройка своего ЖК через PowerShell

Подставьте подтверждённые данные управляющей компании. Пример ниже использует вымышленные значения. В группе узнайте идентификатор через `/chatid@smart_jk_ai_bot` и подставьте его в команду `bind`. Привязка группы выполняется через доступ к локальной базе.

```powershell
.\.venv\Scripts\python.exe -m bot.manage residence example-jk --name "Пример ЖК" --address "Учебный адрес"
.\.venv\Scripts\python.exe -m bot.manage building example-jk A --entrances 3 --apartments 96
.\.venv\Scripts\python.exe -m bot.manage service example-jk "Электрик" --category electricity --description "Диагностика освещения"
.\.venv\Scripts\python.exe -m bot.manage bind example-jk -1001234567890
```

В личном чате выберите этот ЖК командой `/residence example-jk` или перейдите по кнопке из `/request@smart_jk_ai_bot` в привязанной группе. Для проверки смены статуса оператор может выполнить `.\.venv\Scripts\python.exe -m bot.manage status 12 in_progress` с номером тестовой заявки. Допустимые статусы — `new`, `in_progress`, `done`, `rejected`.

При импорте правил конкретного ЖК используйте `--residence example-jk --public`, затем запустите индексацию. Общие законы доступны для всех ЖК. Документы, услуги и карточка выбранного ЖК доступны только в его контексте. Содержимое заявки хранится в PostgreSQL и обрабатывается в личном чате. Для справочных вопросов Gemini получает публичную карточку и каталог выбранного ЖК.

## Автоматические тесты

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты подают входящие обновления в диспетчер aiogram и подменяют запросы к Telegram и Gemini. Для тестов не требуются токен и ключ. Чтобы выполнить интеграционный тест миграций и импорта, задайте `SMART_JK_TEST_DATABASE_URL` для отдельной тестовой базы PostgreSQL. Тест создаёт и удаляет собственную временную схему.

## Структура

- `bot/main.py` регистрирует команды и запускает long polling.
- `bot/config.py` читает настройки из окружения и `.env`.
- `bot/handlers.py` содержит команды, меню, правила ответа в группе и FSM черновика заявки.
- `bot/assistant.py` содержит системный промпт, клиент Gemini и обработку ошибок.
- `bot/catalog.py` содержит общий демонстрационный каталог для команды и ассистента.
- `bot/voice.py` загружает голосовые Telegram с ограничением размера.
- `bot/document_text.py` извлекает текст из PDF и DOCX. `bot/document_store.py` хранит документы в PostgreSQL.
- `bot/documents.py` содержит команды импорта и просмотра. `migrations/` содержит миграции Alembic.
- `bot/knowledge_index.py` готовит фрагменты, `bot/embeddings.py` получает векторы Gemini, а `bot/knowledge.py` ищет подходящие выдержки.
- `bot/residents.py` управляет профилями ЖК, каталогом и заявками. `bot/manage.py` содержит локальные команды оператора.
- `tests/` проверяет маршрутизацию, черновики и обработку ответов Gemini.
